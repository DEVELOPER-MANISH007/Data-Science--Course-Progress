### 7. Type I & Type II Errors

Understanding the two major types of errors that can occur during hypothesis testing.

### Type I Error

Rejecting the null hypothesis when it is actually true.

Also known as:

**False Positive**

### Type II Error

Failing to reject the null hypothesis when it is actually false.

Also known as:

**False Negative**

Topics include:

- Type I Error
- Type II Error
- Significance level
- Statistical decision errors
- Relationship between the two errors
