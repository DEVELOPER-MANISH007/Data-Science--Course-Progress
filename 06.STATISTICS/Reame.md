# Probability & Statistics Notes 📊

A collection of well-organized **Probability and Statistics notes** covering important concepts, probability distributions, statistical estimation, and the Central Limit Theorem.

These notes are useful for students learning **Data Science, Machine Learning, Artificial Intelligence, and Statistics**.

- PMF — Probability Mass Function
- PDF — Probability Density Function
- CDF — Cumulative Distribution Function
